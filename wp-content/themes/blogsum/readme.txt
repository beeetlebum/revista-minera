== Description ==

Blogsum is an authoritative, editorial blog and broadsheet news magazine WordPress theme designed for writers, independent journalists, storytelling bloggers, and modern publications.

As an optimized child theme of Newsum, Blogsum defaults to the Classic Newspaper (Tribune) broadsheet layout, featuring a dedicated three-column editorial grid, prominent lead story focal point, curated brief dispatches, and visual perspective cards.

Blogsum introduces refined editorial typography styling, elevated blockquotes, author highlights, and clean reading aesthetics while inheriting all powerful features from Newsum, including dark/light mode switching, reading time calculations, local GDPR-compliant webfonts, block patterns, and seamless integration with the NewSum Pro suite.

NOTE: Blogsum is a child theme and requires the parent theme "Newsum" to be installed on your WordPress site.

Key Features:
* Pre-configured Classic Newspaper (Tribune) Broadsheet Hero Layout.
* Refined editorial typography and blockquote styling.
* Fully responsive across smartphones, tablets, laptops, and wide screens.
* Built-in Dark and Light mode options.
* GDPR and privacy compliant local Google Font caching.
* Full Accessibility-Ready architecture (WCAG 2.1 AA compliant).
* Live WordPress Customizer controls with instant preview.
* Seamless compatibility with NewSum Pro extensions and demo imports.

== Installation ==

1. Ensure the parent theme "Newsum" is installed: In your WordPress admin dashboard, navigate to Appearance > Themes and install "Newsum".
2. Navigate to Appearance > Themes > Add New > Upload Theme.
3. Choose the `blogsum.zip` file and click "Install Now".
4. Click "Activate" to enable Blogsum.
5. Head to Appearance > Customize to adjust your settings, typography, and colors.

== Frequently Asked Questions ==

= Does Blogsum require the Newsum theme? =
Yes. Blogsum is a child theme built on top of Newsum. Newsum must be installed in your `wp-content/themes/` directory for Blogsum to function.

= Can I change the hero layout if I don't want the Tribune layout? =
Yes! While Blogsum defaults to the Classic Newspaper (Tribune) layout out-of-the-box, you can easily select other layouts (like the 3-Column Bento Slider) in Appearance > Customize > Homepage Hero Section.

= How do I enable Dark or Light mode? =
Visitors can toggle modes via the theme mode button in the header. As an administrator, you can configure the default starting mode in Appearance > Customize > Header & Top Bar Settings.
