== Description ==

Newsum is a high-contrast, modern editorial news and magazine WordPress theme engineered for tech journalism, daily wire publications, venture capital reports, engineering blogs, and digital media houses.

Key Features:
* Dynamic Editorial Hero Switcher (Bento Box, Hover-Reveal Index, Live News Wall, Newspaper Broadsheet, Cyber Terminal).
* GDPR / Privacy Compliant Local Google Font Hosting.
* Full Accessibility-Ready Architecture (WCAG 2.1 AA Compliant with Skip Links, Screen Reader Utilities, and Focus Indicators).
* Live WordPress Customizer Controls with Real-time Selective Refresh.
* Curated Custom Widgets (Editorial Author Profile, Ranked Trending Stories).
* 4+ Curated Block Patterns for Instant Rich Storytelling.
* Built-in Reading Time Estimation and Clean Micro-interactions.
* Dark and Light Theme Modes with Instant Switching.
* Fully Responsive and Mobile-Optimized.

== Installation ==

1. In your WordPress admin dashboard, navigate to Appearance > Themes > Add New.
2. Search for "Newsum" or click "Upload Theme" and upload the newsum.zip file.
3. Click "Install Now" and then "Activate".
4. Navigate to Appearance > Customize to customize your hero layouts, colors, typography, and widgets.

== Frequently Asked Questions ==

= How do I configure the homepage layout? =
Navigate to Appearance > Customize > Homepage Hero Section and select your preferred hero mode (Bento Grid, Hover-Reveal Index, Live Wall, Newspaper Broadsheet, or Terminal).

= How do I switch between Dark and Light mode? =
Visitors can click the theme mode toggle in the header. As an administrator, you can set the default starting mode in Appearance > Customize > Header & Top Bar Settings.

= Are Google Fonts hosted locally? =
Yes! Newsum utilizes the WordPress Theme Team WebFont Loader to automatically download and cache Google Fonts locally on your server, ensuring 100% GDPR and privacy compliance without external tracking calls.
